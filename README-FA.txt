# TANPLUS — نسخه اولیه فول‌استک

## اجرا در ویندوز
1. Node.js نسخه 18 یا جدیدتر را نصب کن.
2. این پوشه را از ZIP خارج کن.
3. داخل پوشه `tanplus` در File Explorer روی نوار آدرس کلیک کن، `cmd` بنویس و Enter بزن.
4. این دستور را اجرا کن:
   `npm install`
5. برای اجرای سایت:
   `npm start`
6. مرورگر را باز کن و برو به:
   `http://localhost:3000`

## امکاناتی که واقعاً کار می‌کنند
- ثبت‌نام و ورود با ایمیل و رمز عبور
- هش کردن رمز عبور با bcrypt
- نگه‌داری نشست ورود
- ذخیره حساب‌ها و پلن انتخاب‌شده در `data/db.json`
- پنل حساب کاربری
- صفحه مربی «محمد مهدی صابر نیک واقف»
- بارگذاری و نمایش تصویر مدارک مربی
- حذف مدارک توسط مدیر
- نمایش سایت در موبایل و دسکتاپ

## ساخت حساب مدیر برای آپلود مدارک
در CMD قبل از اجرای `npm start` این دو دستور را وارد کن (ایمیل و رمز را با مقدار دلخواه خودت جایگزین کن):

Windows CMD:
```bat
set ADMIN_EMAIL=admin@tanplus.local
set ADMIN_PASSWORD=YourStrongPassword123
set SESSION_SECRET=replace-this-with-a-long-random-secret
npm start
```

PowerShell:
```powershell
$env:ADMIN_EMAIL="admin@tanplus.local"
$env:ADMIN_PASSWORD="YourStrongPassword123"
$env:SESSION_SECRET="replace-this-with-a-long-random-secret"
npm start
```

سپس با ایمیل و رمز مدیر وارد شو. دکمه «حساب من» را بزن؛ بخش بارگذاری مدارک فقط برای مدیر نمایش داده می‌شود. مدارک در پوشه `uploads` ذخیره می‌شوند.

## نکات مهم قبل از انتشار عمومی
- این نسخه برای اجرای محلی و آزمایش است؛ از session MemoryStore پیش‌فرض Express استفاده می‌کند.
- برای انتشار واقعی باید session store پایدار، HTTPS، محدودیت درخواست/ضد brute-force، CSRF protection، بکاپ و پایگاه داده production تنظیم شود.
- پرداخت اینترنتی هنوز به درگاه بانکی متصل نیست؛ انتخاب پلن فعلاً در حساب ذخیره می‌شود و هیچ پولی دریافت نمی‌کند.
- دستیار AI و اسکن کالری هنوز به سرویس هوش مصنوعی و API key متصل نیستند؛ بخش‌های مربوطه فعلاً معرفی/نمایشی هستند.
- اطلاعات کاربران در فایل `data/db.json` ذخیره می‌شود. این نسخه را روی هاست عمومی بدون سخت‌سازی امنیتی استفاده نکن.
- قیمت‌ها در فایل `public/index.html` قابل تغییرند.
